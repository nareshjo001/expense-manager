# 💸 Expense Manager – Backend

A secure and scalable **backend API** for the Expense Manager application, responsible for authentication, expense management, budget tracking, and data persistence.

This repository contains the **server-side logic** of the Expense Manager system.

---

## 🚀 Features
- User authentication (Signup & Login)
- JWT-based authorization for protected routes
- Expense CRUD operations
- Monthly budget creation and tracking
- Category and date-based expense filtering
- Secure data storage with MongoDB

---

## 🛠️ Tech Stack
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JSON Web Token (JWT)
- bcrypt.js
- Joi (request validation)
- dotenv & CORS

---

## 🔐 Security
- Password hashing using bcrypt
- JWT tokens with expiry-based sessions
- Auth middleware for protected APIs
- Input validation to prevent malformed requests

---

## 🗂️ Architecture Highlights
- RESTful API design
- Modular folder structure (routes, controllers, models)
- Centralized error handling
- Middleware-driven authorization

---

## 🔗 Frontend Integration
- Designed to integrate seamlessly with the React frontend
- Environment-based configuration for deployment
